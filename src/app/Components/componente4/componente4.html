Niveles y modalidades de estudio

Elige el nivel y la modalidad que mejor se adapte a tus necesidades de aprendizaje.

Niveles de estudio

Nivel Básico

Está dirigido a estudiantes que están iniciando el aprendizaje de un idioma. Permite desarrollar conocimientos fundamentales para comunicarse en situaciones sencillas.

A1 - A2

Nivel Intermedio

Permite fortalecer las habilidades de comprensión y comunicación. El estudiante puede desenvolverse con mayor autonomía en diferentes situaciones.

B1 - B2

Nivel Avanzado

Busca alcanzar un dominio avanzado del idioma, permitiendo una comunicación más fluida y el desarrollo de competencias lingüísticas para contextos académicos y profesionales.

C1

Modalidades de enseñanza

Presencial

El estudiante desarrolla sus clases directamente en las instalaciones, interactuando con docentes y compañeros durante las sesiones de aprendizaje.

A distancia

Permite desarrollar el aprendizaje sin necesidad de asistir físicamente al aula, utilizando recursos y herramientas digitales.

Virtual

Utiliza plataformas y herramientas virtuales para desarrollar las actividades de aprendizaje y facilitar el estudio desde diferentes lugares.

Semipresencial

Combina el aprendizaje virtual con actividades presenciales, ofreciendo flexibilidad y acompañamiento durante el proceso de aprendizaje.
